# LB-LEMUS

Proyecto educativo centrado en la concienciación y formación en ciberseguridad para la comunidad escolar. Diseñado con una arquitectura modular para facilitar la gestión de guías, módulos de auditoría digital, phishing, protección de cuentas, redes sociales, software pirata y videojuegos.

## Tecnologías
- **Frontend:** React 19, TypeScript, Vite.
- **Enrutamiento:** React Router 7.
- **PWA:** Implementación para acceso offline.
- **Iconografía:** Lucide React.

## Instalación

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

## Estructura del Proyecto
La arquitectura sigue un enfoque modular detallado en [docs/arquitectura.md](./docs/arquitectura.md).
- `/src/components`: Componentes reutilizables.
- `/src/pages`: Vistas principales.
- `/src/hooks`: Lógica de negocio encapsulada.
- `/src/data`: Datos estáticos y configuraciones.
