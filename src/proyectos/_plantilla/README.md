# Plantilla para Nuevos Proyectos Estudiantiles

Esta carpeta es una plantilla de punto de partida (boilerplate) para cualquier estudiante o equipo que desee crear un proyecto dentro del sitio de la escuela.

## Instrucciones de uso:
1. Copia toda esta carpeta `_plantilla` y renómbrala con el id de tu proyecto (ej: `robotica`).
2. Edita los archivos `.tsx` y `.css` con el contenido de tu investigación o desarrollo.
3. Registra tu proyecto en `src/config/registroProyectos.ts`.
4. Agrega tu ruta en `src/App.tsx`.
